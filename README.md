# Авторадио

Интернет-радио для машины, у которой магнитола не ловит украинские FM-частоты (американский шаг 0.2 МГц).
Телефон играет потоки станций и передаёт звук в машину по Bluetooth.

## Что умеет (1.0)

- Поиск станций по названию в каталоге [Radio Browser](https://www.radio-browser.info) и добавление по ссылке на поток (.mp3/.aac/.m3u/.pls/.m3u8) с проверкой.
- Плавный переход между станциями: пока новая грузится, старая играет.
- Буфер 10/30/60 с, тихое переподключение при обрыве, отсчёт «хватит ещё на N с» без связи.
- Автозапуск при подключении к Bluetooth машины и пауза при отключении.
- Станция и трек на экране магнитолы, переключение станций кнопками на руле.
- Приглушение под навигатор, пауза на время звонка.

## Что добавилось в 1.1

- Умная пауза, режим «Трасса» (запас до 3 минут), кнопка «Запастись», прогрев при автозапуске.
- Запасные ссылки у станции и понижение качества при слабой связи.
- Выравнивание громкости между станциями.
- История треков с поиском песни, счётчик трафика, «Окей Google, включи … в Авторадио», виджет, сохранение станций в файл.

Всё из «буфера» и «звука» включается и выключается в Настройках.

## Сборка

APK собирает GitHub Actions при каждом пуше в `main`: вкладка **Actions** → последний запуск → **Artifacts** → `car-radio-apk`.
Подпись постоянным ключом из `keystore/`, поэтому новые версии ставятся поверх старых.
